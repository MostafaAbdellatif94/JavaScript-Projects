# C# Projects

These are C# and ASP.NET MVC projects I completed while studying Software and Web Development at The Tech Academy.

## Projects

### Car Insurance
An ASP.NET MVC web application that simulates a car insurance website. It collects policy information, calculates insurance quotes based on business rules, and includes an administrator page for reviewing issued quotes.

### NFL Stats
An ASP.NET MVC application built with Entity Framework 6 using the Code First workflow to store and display fantasy football statistics.
